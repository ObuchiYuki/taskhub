# TaskHub UI規約

## 対象と責務

- macOS 14以降／iOS 17以降のSwiftUIアプリで同じライブラリを使う。
- タスクとユーザー裁定は独立した一覧。裁定一覧はレーン横断を初期表示にする。
- アプリが表示モデル・選択・検索条件・回答・同期状態を所有する。ライブラリは表示と操作の通知を担当する。
- 一覧の検索、サーバー照会、全文検索索引、履歴保存、完了時の証拠必須チェックはアプリ／サーバーの責務。

## 色・文字・余白

- 色は `HubColor` の意味別トークンを参照する。背景 `canvas`、カード `surface`、補助面 `elevatedSurface`、本文 `text`、補助文 `secondaryText`。
- 操作 `accent`、通常の補足 `info`、完了 `success`、要判断／期限間近 `warning`、障害／期限切れ `danger`。
- 強調ボタンは背景 `accent` と文字 `onAccent` を組み合わせる。
- システムのライト／ダーク／コントラスト増加設定に追従する。状態は日本語ラベルとSF Symbolsを併記する。
- 本文はシステムフォント。IDは等幅。`HubTypography` はDynamic Type対応のテキストスタイル。
- `HubSpacing` は4・8・12・16・24・32・48pt。カード余白16pt、セクション間24ptを基本とする。
- 角丸は8・12・16pt。本文の読み幅目安は720pt。広いMac画面では余白か複数列で調整する。
- 通常サイズ文字のコントラストは4.5:1以上、操作境界は3:1以上をパレット単体テストで確認する。無効化操作の減光は対象外。

## 状態

### タスク

- 未着手: 中立色／丸。
- 進行中: 情報色／進行記号。
- ユーザー確認待ち: 警告色／質問記号。
- ブロック: エラー色／停止記号。
- 完了: 成功色／チェック。
- 保留: 中立色／一時停止。

優先度と状態を別表示する。状態・優先度・期限を色だけで区別しない。完了タスク・回答済み以降の裁定は過去期限の警告色を外し、元の期限を表示する。表示コンポーネントは渡された完了証拠を表示する。状態遷移の妥当性は保存元で検証する。

### ユーザー裁定

`未対応 → 回答済み → 反映済み` を独立した状態として表示する。元タスクID、レーン、依頼内容、理由、選択肢、期限、登録者を残す。回答済みは反映完了まで確認対象にできるよう、アプリ側でフィルタを決める。回答欄には回答者・時刻もアプリ側の詳細画面で併記する。

### 期限

`HubDueState.classify` は日時を絶対時刻として比較する。期限より後なら期限切れ、現在から24時間以内（境界を含む）なら期限間近。期限なしも明示する。日付のみの期限は、アプリ側で対象タイムゾーンと日末などの意味を確定してから渡す。

一覧が長時間開かれる場合、アプリ側の `TimelineView(.periodic(from: .now, by: 60))` 等から各行へ同じ `now` を渡す。ライブラリはタイマーを保持しない。

## レイアウトと操作

- Mac／iPadは `NavigationSplitView`、狭いiPhoneは標準のスタック遷移を使う。
- 行タイトル・理由・証拠・ファイル名は改行を許す。重要情報に固定高さを付けない。
- 操作領域は44×44pt以上。ボタン、検索クリア、フィルタはライブラリ内で確保する。
- `HubTaskRow`、`HubDecisionCard`、`HubAttachmentRow` は表示専用。アプリ側の `NavigationLink` または `Button` のラベルとして使う。
- 詳細画面にあるボタンと行全体のボタンは別階層に分ける。
- 通常操作は `HubButton`。既存 `Button`／`NavigationLink` を装飾する場合は `HubButtonStyle`。
- 破壊的操作の確認、キーボードショートカット、フォーカス管理、ページ遷移はアプリ側が担当する。
- 履歴は時系列で追加。利用者名と日時を各行に保持し、編集／削除UIは設けない。
- 同期失敗時は保存済みデータと `HubSyncBanner` を同時表示する。初回読み込み失敗と空一覧を区別する。

## アクセシビリティとプライバシー

- VoiceOverでは行の関連メタデータをまとめて読み上げる。ファイルを開く、詳細へ移動する等の操作ヒントは、ラップするボタン／リンクに付ける。
- フィルタはチェック記号と選択中のアクセシビリティ値を持つ。実行中ボタンは無効化し、処理中を読み上げる。
- Dynamic Type最大、狭い幅、長い日本語、ライト／ダーク、コントラスト増加で確認する。
- 独自アニメーションを使わない。進捗は標準 `ProgressView` に委ねる。
- タイトル・本文・ファイル名・理由はプレーンテキストとして表示する。
- 添付は説明・登録者・日時を表示する。ダウンロード・プレビュー・外部リンク・共有・通信はアプリ側の明示操作に接続する。
- ライブラリとカタログ例にネットワーク通信、解析送信、認証情報、外部公開処理を含めない。
